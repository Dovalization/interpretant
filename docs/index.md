# interpretant

> *Track how words shift meaning over time across philosophical, scientific, and artistic discourse.*

`interpretant` is a diachronic semantic drift tracker for academic corpora. It trains decade-sliced word embeddings, aligns them into a shared vector space, and surfaces vocabulary items whose meanings have measurably shifted.

## Getting started

```bash
make install   # install dependencies
make app-demo  # launch demo dashboard
make test      # run tests
```

See [Architecture](architecture.md) for a technical overview.
